TCExam Installation

Docker (recommended for evaluation)

If you started TCExam with make up (or docker compose up --build), the installation is performed automatically on first start. Read the generated initial password from docker compose logs app, then sign in as admin at admin/code/ and change the password immediately.

Manual / self-hosted install

On your own PHP/web/database stack, first install the PHP dependencies (the bundled libraries — PDF engine, mailer, CAS, RADIUS — are no longer shipped in the source tree):

composer install

The interactive web installer is disabled. Run the command-line installer: set the TCEXAM_DB_* / TCEXAM_PATH_* environment variables and run php install/install_cli.php. Set TCEXAM_ADMIN_PASSWORD or securely record the generated password printed once by the installer. See the script header for the full list.

The full step-by-step manual — system requirements, manual installation and post-installation security — is in install/README.md (also rendered on GitHub), and at the project website tcexam.org.

Important: keep install/ denied at the web-server layer. You may remove it from a production artifact after installation.

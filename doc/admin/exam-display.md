# Отображение экзамена и LiveScore

Дополнительные параметры находятся в «Тесты → Условия доступа» и по
умолчанию выключены.

- **Показывать текущий балл** выводит сумму уже оценённых ответов. Для эссе,
  ожидающего ручной проверки, балл появится только после оценки.
- **Открывать fullscreen** запрашивает полноэкранный режим после первого
  действия участника. Браузер может отклонить запрос; ручная кнопка остаётся.
- **Скрывать служебную информацию** убирает шапку, справку и служебные ссылки
  во время прохождения, не скрывая навигацию самого экзамена.

LiveScore следует включать только там, где мгновенная обратная связь допустима
регламентом. Эти параметры улучшают проведение, но не являются защитой от
второго устройства, фотографирования экрана или изменения User-Agent.

# Автономное электронное проведение

Панель **Тесты → Автономный режим** выдаёт участнику один самодостаточный
HTML-файл. Он открывается без сервера, не выполняет сетевых запросов и не
использует Service Worker, localStorage или другой постоянный браузерный кеш.

Перед выдачей создайте обычную или предварительно сгенерированную попытку.
Выдача пакета запускает отсчёт времени. Срок пакета ограничен длительностью
теста и общей датой его окончания.

Участник отвечает в HTML-файле и нажимает **Скачать черновик / результат**.
Полученный JSON можно загрузить обратно в эту же HTML-страницу для продолжения
или передать организатору для импорта.

## Защита

- Пакет подписан HMAC-SHA-256 ключом конкретной установки.
- Подпись покрывает участника, тест, попытку, срок и точный набор вопросов.
- Правильные ответы и веса в HTML не включаются; оценивание выполняет сервер.
- Сервер сверяет каждый журнал вопроса и допустимые позиции ответов.
- Первый успешный импорт атомарно закрывает попытку.
- Повтор того же файла возвращает безопасный статус `duplicate`.
- Другой результат для уже импортированного пакета возвращает `conflict`.
- Новый пакет отзывает ранее выданный, но ещё не импортированный пакет.

Секрет подписи генерируется криптографически при первой выдаче и хранится в
таблице настроек. Он должен попадать в резервную копию БД и не должен
публиковаться или переноситься между независимыми площадками.

## Ограничения

Текст вопросов и вариантов в автономном HTML показывается как безопасный
обычный текст. Внешние медиа и серверные расширения TCECode не загружаются.
Перед реальным мероприятием отдельно проверьте используемые типы вопросов и
процесс передачи файлов на целевых устройствах.

## Обновление существующей установки

После полного дампа БД примените:

- MySQL/MariaDB — `install/upgrade/mysql/openvsosh_offline.sql`;
- PostgreSQL — `install/upgrade/postgresql/openvsosh_offline.sql`;
- Oracle — `install/upgrade/oracle/openvsosh_offline.sql`.

После обновления на тестовой копии проверьте выдачу, работу без сети, импорт,
повторный импорт, подмену подписи, истечение срока и восстановление БД вместе с
секретом подписи.

# Вложения к развёрнутым ответам

Участник может приложить к текстовому ответу до трёх файлов. Поддерживаются
JPEG, PNG и PDF размером до 5 МБ каждый. Файл сохраняется при обычной отправке
формы ответа; текст ответа по-прежнему можно сохранять отдельной AJAX-кнопкой.

Сервер не доверяет имени и типу из браузера:

- MIME определяется по содержимому через `finfo`;
- изображения дополнительно декодируются, PDF проверяется по сигнатуре;
- SVG, HTML, офисные документы, архивы и исполняемые форматы отклоняются;
- имя в хранилище — случайная 64-символьная строка без расширения;
- при выдаче повторно проверяется SHA-256;
- прямой HTTP-доступ к `cache/attachments` закрыт, файлы выдаются только
  контроллером после проверки владельца или прав проверяющего.

Вложения видны участнику и проверяющему рядом с ответом. Изображения включаются
в PDF, для остальных файлов PDF содержит имя, MIME и размер. Кнопка ZIP на
странице попытки создаёт архив работы с `manifest.json`, текстами ответов,
баллами, файлами и их SHA-256, но без ключей правильных ответов.

При развёртывании не на Apache закройте `/cache/attachments/` в конфигурации
веб-сервера. Например, для nginx:

```nginx
location ^~ /cache/attachments/ { deny all; return 404; }
```

## Обновление существующей базы

Примените миграцию:

- MySQL/MariaDB — `install/upgrade/mysql/openvsosh_essay_attachments.sql`;
- PostgreSQL — `install/upgrade/postgresql/openvsosh_essay_attachments.sql`;
- Oracle — `install/upgrade/oracle/openvsosh_essay_attachments.sql`.

Каталог `cache/attachments` должен быть доступен на запись PHP-процессу и
включён в резервное копирование вместе с базой данных.

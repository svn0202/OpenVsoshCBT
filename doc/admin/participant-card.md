# Карточка участника

В редакторе пользователя администратор может сохранить внутреннюю заметку,
расписание и фотографию участника.

Фотография принимается только как JPEG или PNG размером до 5 МБ. Сервер
декодирует изображение, уменьшает его до 1024 пикселей и заново записывает
JPEG вне публичного каталога. Получить файл может сам участник либо
администратор с правом управления пользователями.

Расписание показывается участнику в боковой панели. Внутренняя заметка остаётся
только в административной карточке и не выводится в публичной части.

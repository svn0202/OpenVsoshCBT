# Импорт вопросов из Microsoft Word

OpenVsoshCBT содержит собственный безопасный импортёр DOCX. Он читает только
части формата OOXML, не исполняет макросы и OLE-объекты, не загружает внешние
изображения и не требует CKEditor Cloud Services.

## Миграция существующей базы

В новой установке поле веса ответа уже входит в основную схему. Перед
обновлением существующей установки сделайте дамп БД и один раз примените файл
для своей СУБД:

- PostgreSQL — `install/upgrade/postgresql/openvsosh_word_import.sql`;
- MySQL/MariaDB — `install/upgrade/mysql/openvsosh_word_import.sql`;
- Oracle — `install/upgrade/oracle/openvsosh_word_import.sql`.

При нестандартном префиксе таблиц замените `tce_` в SQL-файле. Откат требует
удаления ограничения `chk_tce_answers_weight`, затем столбца
`answer_weight`; предварительно выгрузите вопросы, если веса уже используются.

## Формат документа

Сохраните документ как обычный `.docx`:

```text
MODULE:=Название модуля
TOPIC:=Название темы

Q:1) Формулировка вопроса
A:) Первый вариант
B:) Второй вариант
RIGHT:A
```

Поддерживаются одиночный и множественный выбор, текстовый ответ, ordering,
таблицы с объединёнными ячейками, встроенные JPEG/PNG/GIF, формулы OOXML,
выравнивание, жирный, курсив, подчёркивание, цвет текста и заливка. Документ
Google Docs сначала скачайте в формате Microsoft Word (`.docx`).

Дополнительные метки:

- `[[TMF_CHECKBOX]]` — использовать флажки для конкретного вопроса MCMA;
- `[[MCMA_HEADER:=Утверждение,Да,Нет,Без ответа]]` — задать четыре подписи
  табличного MCMA;
- `[[MAX_SEL=2]]` — разрешить не больше двух выбранных вариантов;
- `[[SHORT_ANSWER]]` — считать варианты допустимыми ключами краткого ответа;
- `[[DIFFICULTY=3]]` — сложность от 1 до 5;
- `[[TIMER=60]]` — таймер вопроса в секундах;
- `[[AUTO_NEXT]]` — автоматический переход после ответа или таймера;
- `[[WEIGHT=50]]` в варианте ответа — 0–100 процентов максимального балла.

Если вес не указан, действует стандартная схема оценивания TCExam. Вес
используется для выбранного варианта одиночного ответа и для точного
совпадения краткого ответа.

## Порядок работы

1. Откройте «Модули → Импорт Word».
2. Загрузите копию DOCX; оригинал не изменяется.
3. Проверьте модуль, тему, количество вопросов, типы и ключи.
4. Подтвердите импорт.
5. Откройте созданную тему и выборочно проверьте вопросы в браузере.

База изменяется только после подтверждения. Модуль, тема, вопросы и ответы
создаются одной транзакцией. При совпадении имени темы создаётся новая тема с
суффиксом даты и времени; одинаковые формулировки вопросов разрешены.

## Ограничения и безопасность

- DOCX — не более 20 МБ, распакованное содержимое — не более 100 МБ и 5000
  элементов архива.
- Внешние изображения, небезопасные пути ZIP и неподдерживаемые форматы
  изображений отклоняются.
- EMF/WMF преобразуйте в PNG перед импортом.
- Сложные формулы после преобразования в MathML проверьте на рабочих
  браузерах.
- Загружайте сначала в тестовую базу. Импортёр не заменяет резервное
  копирование и предметную проверку ключей.

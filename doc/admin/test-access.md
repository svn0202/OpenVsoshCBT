# Условия доступа и безопасного завершения

Страница «Тесты → Условия доступа» добавляет серверные правила поверх обычных
дат, групп, IP-диапазона и токена TCExam.

Для теста можно указать:

- тест, который участник должен сначала завершить;
- тест, который участник должен сначала пройти по его проходному баллу;
- минимальное время до добровольного завершения;
- обязательность ответа на все вопросы сформированной попытки;
- запрет завершения, пока текущий балл ниже проходного;
- отключение кнопок «Назад» и «Далее»;
- простой режим развёрнутого ответа без загрузки rich-text-редактора;
- текстовое сообщение после успешного завершения.

Зависимости не могут ссылаться на сам тест или образовывать цикл. Участник с
уже начатой попыткой продолжает её, даже если администратор позже изменил
условия. Токен можно сменить во время проведения: браузеры, уже успешно
введшие прежний токен, сохраняют допуск в своей авторизованной сессии, а новые
участники вводят новый.

Сообщение после завершения выводится как безопасный текст на внутренней
странице. Внешние URL и HTML из этого поля не исполняются.

Генератор также проверяет, что выбранные наборы дали заявленное количество
вопросов. Неполная попытка при нехватке банка не открывается.

## Обновление существующей базы

Перед включением правил примените один файл:

- MySQL/MariaDB — `install/upgrade/mysql/openvsosh_test_access.sql`;
- PostgreSQL — `install/upgrade/postgresql/openvsosh_test_access.sql`;
- Oracle — `install/upgrade/oracle/openvsosh_test_access.sql`.

После миграции проверьте на тестовой копии закрытый prerequisite, проходной
балл, продолжение активной попытки, смену токена и все варианты завершения.

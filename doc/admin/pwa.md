# Установка OpenVsoshCBT как приложения

Публичная часть OpenVsoshCBT содержит Web App Manifest и Service Worker.
Поддерживаемый браузер может предложить «Установить приложение» после открытия
публичной страницы по HTTPS (для локальной проверки также разрешён localhost).

Service Worker намеренно не обеспечивает автономное прохождение экзамена. Он
кеширует только два публичных графических ресурса из фиксированного списка.
Страницы экзамена, административная часть, токены, результаты, API, cache и
любые URL с параметрами всегда загружаются из сети с `cache: no-store`.

## Проверка

1. Откройте публичную страницу в Chrome/Edge по HTTPS.
2. В DevTools → Application → Manifest убедитесь, что manifest распознан.
3. В Service Workers убедитесь, что активен `/public/sw.js`.
4. В Cache Storage должен быть только `openvsosh-public-static-v1` с
   `/public/pwa-icon.svg` и `/images/vsosh-logo.png`.
5. Начните тест и проверьте, что запросы `/public/code/` отображаются как
   сетевые, а их ответы отсутствуют в Cache Storage.

Для полноценного автономного экзамена используйте подписанные автономные
пакеты из административного интерфейса, а не Service Worker.

# Вопросы на сопоставление

Тип `MATCHING` используется для установления соответствий между двумя наборами
элементов. По умолчанию соответствие взаимно-однозначное; настройка
**Разрешать повтор позиций** включает режим «один ко многим».

## Создание вопроса

1. В редакторе вопроса выберите тип **Сопоставление**.
2. В тексте вопроса разместите пронумерованную левую колонку, например:

   ```text
   1. Россия
   2. Беларусь
   3. Казахстан
   ```

3. Создайте варианты правой колонки и укажите для каждого правильную позицию:

   | Вариант ответа | Позиция |
   |---|---:|
   | Москва | 1 |
   | Минск | 2 |
   | Астана | 3 |

4. Используйте позиции подряд, начиная с `1`. Позиции включённых вариантов не
   должны повторяться, если не включена настройка **Разрешать повтор позиций**.

Если одному условию должны соответствовать несколько вариантов, включите
**Разрешать повтор позиций** и назначьте этим вариантам одинаковую позицию.
Например, позиции `1, 1, 2, 3, 3` задают две группы с несколькими вариантами.

Если число условий и вариантов различается, задайте в редакторе вопроса
**Количество условий matching**. Например, значение `3` оставит в каждом списке
позиции 1–3 даже при наличии пяти вариантов (два из них могут быть отвлекающими).
Ноль сохраняет прежнее поведение: число позиций равно числу вариантов.

Участник выбирает номер соответствующего элемента возле каждого варианта.
В обычном режиме повторное назначение номера очищает его предыдущее назначение.
При включённом повторе один номер можно назначить нескольким вариантам. Все
элементы управляются обычными HTML-списками выбора и доступны с клавиатуры.

## Баллы

При включённом частичном балле каждая пара оценивается отдельно, после чего
сумма делится на число пар. При выключенном частичном балле вопрос приносит
полный балл только при правильном сопоставлении всех элементов.

Перед публикацией проверьте полностью правильный ответ, одну переставленную
пару, пропущенную пару и попытку повторно использовать одну позицию.

# Оформление площадки

Администратор уровня 10 может изменить оформление на странице
`Администрирование → Настройки площадки`.

Доступны название и описание площадки, контакт, приветствие участника,
дополнительная инструкция входа, основной логотип и фон страницы входа.
Текстовые поля сохраняются как обычный текст: HTML и сценарии из них не
исполняются.

Здесь же выбираются язык и часовой пояс по умолчанию. Они сохраняются в
базе и в защищённом загрузочном JSON-файле внутри `shared/config`, потому
что перевод и часовой пояс нужны приложению до открытия пользовательской
сессии. Файл не содержит паролей и закрыт от HTTP-доступа вместе с остальной
конфигурацией.

Для таймера задаются пороги предупреждения и критического состояния в
секундах, а также цвета. Критический порог не может превышать обычный.
Интерфейс показывает состояние не только цветом, но и текстом; цвет текста
автоматически выбирается чёрным или белым с контрастом не ниже 4.5:1.

Для логотипа и фона принимаются только корректные JPEG и PNG размером от
32×32 до 8192×8192 пикселей и объёмом не более 5 МБ. Тип файла проверяется
по содержимому, а не по расширению. Изображения получают случайные имена,
хранятся в `cache/site-assets` без права исполнения и выдаются только через
проверяющий контроллер. При замене предыдущий файл удаляется после успешного
сохранения нового.

Каталог `cache/site-assets` и файл `shared/config/openvsosh-bootstrap.json`
необходимо включать в резервную копию вместе с базой данных. Если
восстановить только базу, пользовательское изображение не будет выдано,
пока файл с совпадающей контрольной суммой не появится в хранилище.

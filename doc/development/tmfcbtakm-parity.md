# Матрица функционального паритета TMFCBT/TMFCBTAKM

Дата сверки: 2026-07-27.

Эта таблица фиксирует проверенные пользовательские сценарии, а не заявляет
полный паритет с закрытыми редакциями. Источником для переноса служат
публично описанные сценарии и доступная рабочая установка; закрытый код не
копируется.

| Область | Статус OpenVsoshCBT | Подтверждение или ограничение |
|---|---|---|
| Word/DOCX и материалы Google Docs | реализовано | OOXML-парсер, preview, изображения, таблицы, формулы, безопасная очистка и транзакционный импорт |
| CKEditor 5 Word Import v2 | не применяется | текущий импорт не зависит от коммерческой лицензии CKEditor |
| MATCHING, ORDERING, веса, MAX_SEL | реализовано | модель, редактор, сохранение и повторное оценивание покрыты unit-тестами; полная браузерная приёмка остаётся стендовой |
| Вложения к эссе | реализовано | MIME/размер/число, закрытое хранение, права доступа, PDF и архив |
| Условия доступа и завершения | реализовано | prerequisites, минимум времени, обязательные ответы и порог |
| Наблюдение | реализовано | статусы, блокировка, разблокировка, продление, безопасный сброс и аудит |
| Роли 1–10 | реализовано без уровня «родитель» | уровень 4 не добавляется без отдельной модели согласий и видимости данных |
| LiveScore и мобильный UI | реализовано | Chromium 390 × 844 принят без горизонтального переполнения; реальные Android/WebView/планшеты остаются обязательными |
| Арабский текст | реализовано | встроен Noto Sans Arabic WOFF2, точный DOCX round-trip и Chromium RTL приняты; нужны целевые Linux/Android |
| Аудио | реализовано | лимит хранится на клиенте и принят в Chromium с reload; требуется матрица реальных браузеров и аппаратного звука |

| Автономный электронный режим | реализовано, автоматизированная приёмка пройдена | подпись, срок, привязка, идемпотентный импорт, потерянный ответ и конфликт версий проверены; нужен целевой полевой сценарий |

| Oracle | статическая совместимость | миграции подготовлены; интеграционный Oracle-стенд отсутствует |

## Условия для будущего заявления паритета

Полный паритет можно обсуждать только после:

1. приёмки всех типов вопросов с переходом, reload и восстановлением сети;
2. проверки мобильных браузеров, Android WebView и listening-тестов;
3. нагрузочного прогона с фактическим профилем участников;
4. аварийного прогона offline, backup и restore;
5. сопоставления результатов HTML, PDF, TSV, XML, JSON и XLSX на одном
   зафиксированном наборе попыток.
